# Next.js Feedback Widget SDK

Embeddable customer feedback collection widget SDK and administrative review analytics dashboard built with Next.js 14 App Router, React 18, TypeScript, and Tailwind CSS.

## Features

- **Embeddable Floating Widget**: Drop-in customer feedback modal with star ratings, category tagging (Bug, Feature, Praise, General), comment capture, and email support.
- **Admin NPS Analytics Dashboard**: Real-time satisfaction metric calculations, rating distributions, and feedback status lifecycle tracking.
- **REST Telemetry API**: `/api/feedback` Route Handler for recording feedback and querying analytics summaries.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Production Build

```bash
npm run build
npm start
```
